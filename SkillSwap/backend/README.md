# Backend SkillSwap

A documentação de frontend, backend, banco de dados, operação, segurança está unificada na raiz: [`../README.md`](../README.md).

O backend é Spring Boot 3, Java 21, Firebase Resource Server, PostgreSQL/Flyway, Redis e Stripe Checkout para SwapCoins. Segredos são injetados por ambiente; não coloque credenciais neste diretório.
