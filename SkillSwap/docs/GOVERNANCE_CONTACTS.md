# Governança de privacidade

Este arquivo registra as pessoas que precisam ser oficialmente nomeadas antes de o SkillSwap ser publicado para usuários reais. Os campos não preenchidos não são uma autorização para produção.

- País e endereço de contato: **PREENCHER**

O controlador é quem decide por que e como os dados pessoais são tratados. Se o projeto for apenas acadêmico, a equipe deve confirmar com a UCSAL quem responde pelo ambiente de teste e quem será o controlador em eventual operação independente.
