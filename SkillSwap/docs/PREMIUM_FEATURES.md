# Recursos comerciais fora do escopo

A versão atual da SkillSwap é gratuita para os usuários. Carteira, SwapCoins, Stripe, compras, gorjetas, limites pagos e recursos premium não fazem parte do fluxo da aplicação.

As rotas comerciais são bloqueadas pela API e não aparecem na navegação do frontend. Este arquivo permanece apenas para registrar que os módulos antigos foram desativados; nenhuma pessoa precisa comprar créditos para utilizar cadastro, perfil, feed, propostas, conversa, aulas ou acessibilidade.
